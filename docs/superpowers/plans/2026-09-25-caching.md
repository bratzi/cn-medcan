# Caching gegen Fehler 1102 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die Hauptseiten laufen bei warmem Cache ohne D1-Abfrage und unter 10 ms CPU je Request.

**Architecture:** Next-16-Cache-Components (`cacheComponents: true`). Geteilte Daten und deren UI werden als
`"use cache"`-Komponenten mit `cacheLife({ revalidate: 300 })` und Tags gecacht; die Rolle bzw. Sitzung liest
eine ungecachte Komponente in einer `<Suspense>`-Grenze und reicht nur einfache Werte hinein. OpenNext speichert
in KV hinter dem Regional Cache, Tags in einer eigenen D1-Datenbank.

**Tech Stack:** Next 16.3.6, @opennextjs/cloudflare 1.20.6, Prisma 7 mit D1, Tests `npm test` (tsx --test).

**Spec:** `docs/superpowers/specs/2026-09-25-caching-design.md`

## Global Constraints

- Nur Free-Plan-Dienste mit harter Grenze: KV, D1, Regional Cache. **Kein R2, kein Paid, keine Queue auf DO.**
- Frische: `cacheLife({ stale: 60, revalidate: 300, expire: 3600 })` für alle geteilten Daten.
- Nie `cookies()`, `headers()`, `lib/session`, `lib/query/fachkreis` innerhalb einer `"use cache"`-Einheit.
- Kein lokales `next dev`/`build`/`preview` (Projektregel „Live statt Dev“): pushen, Cloudflare baut, live mit
  `npx wrangler tail cn-medcan --format json` und Browser prüfen. Keine Polling-Schleifen.
- Dateien mit CRLF bleiben CRLF (nach `sed` prüfen).
- UI-Änderungen nach `.claude/skills/ui-design-engine.md`, Datenzugriff nach `.claude/skills/edge-stack-master.md`.
- Commit-Nachrichten deutsch, Conventional Commits, mit `Co-Authored-By`-Zeile.

## Review Focus

1. Anmeldung/Abmeldung wechselt die Preisanzeige sofort — Preise dürfen nie aus der falschen Rollen-Fassung kommen (Test in Task 2).
2. Build auf Cloudflare ohne erreichbare Datenbank darf nicht abbrechen und keinen leeren Katalog für 5 Minuten einfrieren (Task 1, Schritt 4).
3. Unbekannte oder böswillige Filterparameter auf `/produkte` erzeugen keinen unbegrenzten Schlüsselraum in KV (Test in Task 3).
4. Unbekannter Slug auf `/produkte/[slug]` antwortet weiter mit 404, auch aus dem Cache (Task 4, Schritt 3).
5. Eigene Stimme erscheint direkt nach dem Abstimmen, obwohl der Zählstand bis 5 Minuten nachläuft (Task 5, Live-Prüfung).

### Task 2: Wache gegen Nutzerdaten im Cache

**Files:**
- Create: `tests/cache-ohne-nutzerdaten.test.ts`

- [ ] **Step 1: Test schreiben**

```ts
import { test } from "node:test";
import assert from "node:assert/strict";
import { readFileSync, readdirSync, statSync } from "node:fs";
import { join } from "node:path";

const VERBOTEN = [/from "@\/lib\/session"/, /from "@\/lib\/query\/fachkreis"/, /\bcookies\(\)/, /\bheaders\(\)/];

function dateien(ordner: string): string[] {
  return readdirSync(ordner).flatMap((name) => {
    const pfad = join(ordner, name);
    return statSync(pfad).isDirectory() ? dateien(pfad) : /\.tsx?$/.test(name) ? [pfad] : [];
  });
}

/** Rumpf jeder Funktion mit "use cache" grob herausschneiden: bis zur nächsten Top-Level-Funktion. */
function gecachteRuempfe(quelle: string): string[] {
  return quelle.split(/\n(?=(?:export )?(?:async )?function )/).filter((teil) => /["']use cache["']/.test(teil));
}

test("keine gecachte Einheit liest Sitzung, Rolle, Cookies oder Header", () => {
  for (const datei of [...dateien("app"), ...dateien("components"), ...dateien("lib")]) {
    for (const rumpf of gecachteRuempfe(readFileSync(datei, "utf8"))) {
      for (const muster of VERBOTEN) {
        assert.ok(!muster.test(rumpf), `${datei}: gecachte Funktion nutzt ${muster}`);
      }
    }
  }
});

test("gecachte Einheiten tragen ein cacheLife", () => {
  for (const datei of [...dateien("app"), ...dateien("components"), ...dateien("lib")]) {
    for (const rumpf of gecachteRuempfe(readFileSync(datei, "utf8"))) {
      assert.match(rumpf, /cacheLife\(FRIST\)/, `${datei}: "use cache" ohne cacheLife(FRIST)`);
    }
  }
});
```

FAIL mit Dateiname. Zurücknehmen, `npm test` → PASS.
- [ ] **Step 3:** Commit `test: Wache gegen Nutzerdaten in gecachten Einheiten`.

- [ ] **Step 3: Implementierung** in `lib/query/filter.ts`

```ts
/** Cache-Schlüssel des Filters: nur bekannte Felder, sortiert (begrenzt den KV-Schlüsselraum). */
export function filterSchluessel(filter: StrainFilter): string {
  const params = serialisiereFilter(filter);
  params.sort();
  return params.toString();
}
```
